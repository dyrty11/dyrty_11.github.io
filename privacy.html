Сайт использует файлы cookie для сохранения выбранной темы (светлая/темная). Данные технического характера не передаются третьим лицам.

При отправке сообщения через форму обратной связи (Formcarry) вы добровольно предоставляете ваше имя и адрес электронной почты исключительно для ответа на ваше обращение.


2. Использование данных

Мы не продаем, не обмениваем и не передаем ваши персональные данные третьим лицам. Данные используются только для коммуникации.


3. Согласие

Используя этот сайт, вы соглашаетесь с условиями данной Политики конфиденциальности.
