Online Admin

Редактирование projects.json напрямую на GitHub.

Токен хранится только в вашем браузере (localStorage). Он не отправляется никуда, кроме api.github.com.
Не подключено
Готов к работе.
Как пользоваться:
1. Вставьте токен и нажмите «Загрузить из GitHub».
2. Редактируйте проекты.
3. Нажмите «Сохранить на GitHub» — файл projects.json обновится в репозитории.
4. GitHub Pages подхватит изменения через 1–2 минуты.
