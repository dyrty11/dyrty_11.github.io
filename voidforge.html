💀 Soundtag Пранки

Soundtag — это NFC-метка со ссылкой на сайт. Когда пранкер прикладывает метку к телефону жертвы, у неё появляется системное уведомление (например, «Открыть ссылку?»). Жертва нажимает на него, открывается страница с картинкой, и только после клика по самой картинке воспроизводится громкий мемный звук.

⚠️ Важно: У жертвы должен быть включен NFC в настройках телефона (у большинства Android он включен по умолчанию, у iPhone нужно просто разблокировать экран).

🛠️ Инструкция по созданию

01
Сгенерируй файл

Загрузи картинку и звук выше, нажми «Сгенерировать» и скачай файл index.html.

02
Залей файл в сеть (Хостинг)

Метка хранит только ссылку. Самый анонимный и быстрый способ:

  • Зайди на app.netlify.com/drop
  • Перетащи папку с файлом index.html прямо в браузер
  • Получи готовую ссылку вида https://random-name.netlify.app
03
Запиши ссылку на метку

Скачай бесплатную версию NFC Tools:

  • NFC Tools для Android (Google Play)
  • NFC Tools для iOS (App Store)

Открой вкладку «Записать» → «Добавить запись»:

  • Выбери URL / URI и вставь полученную ссылку
  • Нажми «Записать» и приложи телефон к метке
04
Иди троллить

Подойди к жертве (в наушниках, в толпе, в транспорте) и приложи метку к её смартфону. У жертвы появится уведомление о переходе по ссылке. Когда она нажмёт на него — откроется картинка. Как только она тапнет по картинке, прогремит звук!

⚠️ Используй только для безобидных пранков. Не оставляй метки без присмотра и не прикладывай их к чужим устройствам без согласия.
